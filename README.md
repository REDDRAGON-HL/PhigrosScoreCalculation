# Phigros 分数计算器

输入目标分数和谱面物量，计算达到该分数所需的 Perfect、Good、Miss 数量及最大连击数。

***

## 功能类型

| 功能            | 说明                            |
| ------------- | ----------------------------- |
| **固定分数计算**    | 输入目标分数和物量，找出所有可能的 P/G/M 组合    |
| **固定 ACC 计算** | 输入目标 ACC 和物量，找出所有可能的 P/G/M 组合 |
| **区间分数计算**    | 输入分数范围，找出该范围内的所有可能组合          |
| **区间 ACC 计算** | 输入 ACC 范围，找出该范围内的所有可能组合       |
| **单曲 RKS 计算** | 简单的 RKS 计算公式                  |

## 算法说明

### 1. 常规算法

- 暴力穷举，遍历所有可能的 P、G、LJS 组合
- 实现简单，效果稳定
- 速度最慢

### 2. 剪枝算法

- 通过公式直接计算所需连击数
- 结合连击分范围进行剪枝
- 速度较快

### 3. 范围剪枝

- 在剪枝算法基础上，提前计算每个 P 的有效分数范围，大幅跳过不可能的组合
- 速度很快

### 4. 二分剪枝

- 对 G 值进行二分查找定位候选点
- 在候选点附近搜索验证
- 速度很快，结果太多时可能有部分遗漏

### 5. 神秘算法（范围枚举）

- 利用公式反推 P 和 G 的可能范围
- 大幅缩小搜索空间后枚举
- 速度最快，但可能不太稳定

## 使用方法

1. 运行程序
2. 选择功能：
   - **固定分数计算**：输入目标分数和物量
   - **固定 ACC 计算**：输入目标 ACC 和物量
   - **区间分数计算**：输入分数范围和物量
   - **区间 ACC 计算**：输入 ACC 范围和物量
   - **单曲 RKS 计算**：输入定数和 ACC
3. 选择算法
4. （可选）勾选"课题模式"和"导出结果"
5. 点击"运行"查看结果
